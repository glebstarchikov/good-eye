# Good Eye Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A local-first design inspiration database (websites + apps) with a Playwright capture pipeline, a headless-Claude "librarian" analysis pass, SQLite/FTS5 search, an MCP server usable from Claude Code / Claude Desktop / Codex, plus a skill and a UserPromptSubmit hook.

**Architecture:** One Node/TypeScript package run via `tsx` (no build step). Files under `data/designs/<slug>/` are the source of truth (`meta.json`, `analysis.md`, images, tokens); `data/catalog.db` is a derived, rebuildable index. Capture (Playwright) and analysis (`claude -p` on the user's subscription) are library functions shared by a thin CLI and the MCP server.

**Tech Stack:** Node ≥20 (dev machine has v24), ESM + TypeScript via `tsx`, `@modelcontextprotocol/sdk` **v1.x** (stable line — NOT the 2.0 alpha `@modelcontextprotocol/server`), `playwright` (chromium only), `better-sqlite3`, `sharp`, `node-vibrant` v4, `zod` **v3** (`^3.25`, required by MCP SDK v1), `node:test` as the test runner.

**Spec:** `docs/superpowers/specs/2026-07-11-design-inspiration-db-design.md`. Two deliberate deviations, both agreed rationale: (1) MCP progress notifications are downgraded to `console.error` logging (v1 SDK progress needs client-provided tokens; stderr shows in MCP logs); (2) `meta.status` lifecycle is clarified: capture writes `needs-analysis` (clean) or `partial` (degraded); successful analysis promotes `needs-analysis → complete` and leaves `partial` as `partial`; failed analysis leaves status untouched.

## Global Constraints

- ESM everywhere: `"type": "module"`; relative imports use `.js` suffix (`import { x } from "./paths.js"`), required by `moduleResolution: NodeNext`.
- No build step: everything runs through `tsx` (`node --import tsx`).
- Tests: `node --import tsx --test tests/<file>.test.ts`; full suite via `npm test`. Every test that touches data calls `tempDataDir()` from `tests/helpers.ts` so `GOOD_EYE_DATA_DIR` points at a throwaway dir — never the real `data/`.
- `data/` stays gitignored (already in `.gitignore`).
- Env overrides (read at call time, never cached at module load): `GOOD_EYE_DATA_DIR` (data location), `GOOD_EYE_CLAUDE_BIN` (librarian binary, default `claude`), `GOOD_EYE_MODEL` (default `sonnet`).
- Never `console.log` from `src/` library or server code — stdout is the MCP protocol channel. Use `console.error`. The CLI (`src/cli.ts`) is the only file allowed to print to stdout.
- MCP SDK v1 API: `new McpServer({name, version})`, `server.registerTool(name, {description, inputSchema: <ZodRawShape>}, handler)`, `await server.connect(new StdioServerTransport())`. Image content blocks: `{ type: "image", data: <base64>, mimeType: "image/jpeg" }`.
- Controlled vocabularies (categories, style tags, component types) live ONLY in `src/lib/vocab.ts` — spec §5.1/§5.2 copied verbatim there; librarian prompt and schemas import them.
- All commits end with the trailer: `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`
- claude CLI ≥ 2.1 verified present with `-p`, `--output-format json`, `--model`, `--allowedTools`, `--add-dir`.

```typescript
  return path.join(designsDir(), slug);
}
export function dbPath(): string {
  return path.join(dataDir(), "catalog.db");
}

/** "https://www.Stripe.com/" -> "stripe-com--2026-07-11" */
export function makeSlug(name: string, date: Date = new Date()): string {
  const clean = name
    .toLowerCase()
    .replace(/^https?:\/\//, "")
    .replace(/^www\./, "")
    .replace(/[^a-z0-9]+/g, "-")
    .replace(/^-+|-+$/g, "")
    .slice(0, 60);
  return `${clean}--${date.toISOString().slice(0, 10)}`;
}

export function ensureDir(p: string): void {
  fs.mkdirSync(p, { recursive: true });
}
```

```typescript
import fs from "node:fs";
import path from "node:path";
import { z } from "zod";
import { designDir, designsDir } from "./paths.js";
import { CATEGORIES } from "./vocab.js";

const PaletteEntry = z.object({
  hex: z.string().regex(/^#[0-9a-fA-F]{6}$/),
  role: z.enum(["primary", "accent", "background", "surface", "text"]),
  prominence: z.number().min(0).max(1),
});

const Typography = z.object({
  families: z.array(z.string()).default([]),
  scale: z.string().default(""),
  notes: z.string().default(""),
});

export const MetaSchema = z.object({
  slug: z.string(),
  source_type: z.enum(["web", "app"]),
  platform: z.enum(["web", "ios", "android", "macos"]),
  url: z.string().nullable(),
  domain: z.string(), // hostname for web, app name for apps
  title: z.string().default(""),
  category: z.enum(CATEGORIES as unknown as [string, ...string[]]).default("other"),
  status: z.enum(["complete", "partial", "needs-analysis"]),
  captured_at: z.string(),
  note: z.string().default(""),
  tags: z.array(z.string()).default([]),
  palette: z.array(PaletteEntry).default([]),
  typography: Typography.default({}),
  components: z.array(z.object({ type: z.string(), path: z.string(), description: z.string() })).default([]),
  screens: z.array(z.object({ name: z.string(), path: z.string(), description: z.string() })).default([]),
});
export type Meta = z.infer<typeof MetaSchema>;

/** What the librarian (claude -p) must return. `file` refers to an existing provisional image path. */
export const LibrarianOutputSchema = z.object({
  category: z.enum(CATEGORIES as unknown as [string, ...string[]]),
  tags: z.array(z.string()).min(1).max(10),
  palette: z.array(PaletteEntry).min(1).max(8),
  typography: Typography,
  components: z.array(z.object({ file: z.string(), type: z.string(), description: z.string() })).default([]),
  screens: z.array(z.object({ file: z.string(), name: z.string(), description: z.string() })).default([]),
  review: z.string().min(100),
});
export type LibrarianOutput = z.infer<typeof LibrarianOutputSchema>;

export function readMeta(slug: string): Meta {
  const p = path.join(designDir(slug), "meta.json");
  if (!fs.existsSync(p)) throw new Error(`No design entry "${slug}" (missing ${p})`);
  return MetaSchema.parse(JSON.parse(fs.readFileSync(p, "utf8")));
}

export function writeMeta(meta: Meta): void {
  fs.writeFileSync(path.join(designDir(meta.slug), "meta.json"), JSON.stringify(meta, null, 2));
}

export function listSlugs(): string[] {
  if (!fs.existsSync(designsDir())) return [];
  return fs.readdirSync(designsDir())
    .filter((d) => fs.existsSync(path.join(designsDir(), d, "meta.json")))
    .sort();
}

export function readAnalysis(slug: string): string {
  const p = path.join(designDir(slug), "analysis.md");
  return fs.existsSync(p) ? fs.readFileSync(p, "utf8") : "";
}

export function writeAnalysis(slug: string, text: string): void {
  fs.writeFileSync(path.join(designDir(slug), "analysis.md"), text);
}

export function domainFromUrl(url: string): string {
  return new URL(url).hostname.replace(/^www\./, "");
}
```

```typescript
import Database from "better-sqlite3";
import { dataDir, dbPath, ensureDir } from "./paths.js";
import { listSlugs, readAnalysis, readMeta, type Meta } from "./meta.js";

const SCHEMA = `
CREATE TABLE IF NOT EXISTS designs (
  id INTEGER PRIMARY KEY,
  slug TEXT UNIQUE NOT NULL,
  url TEXT, domain TEXT, title TEXT,
  source_type TEXT NOT NULL CHECK(source_type IN ('web','app')),
  platform TEXT, category TEXT, status TEXT,
  captured_at TEXT NOT NULL, note TEXT
);
CREATE TABLE IF NOT EXISTS tags       (design_id INTEGER REFERENCES designs(id), tag TEXT);
CREATE TABLE IF NOT EXISTS components (design_id INTEGER REFERENCES designs(id), type TEXT, path TEXT, description TEXT);
CREATE TABLE IF NOT EXISTS colors     (design_id INTEGER REFERENCES designs(id), hex TEXT, role TEXT, prominence REAL);
CREATE VIRTUAL TABLE IF NOT EXISTS designs_fts USING fts5(
  slug, title, category, tags, note, analysis, components_text
);
`;

export function openDb(): Database.Database {
  ensureDir(dataDir());
  const db = new Database(dbPath());
  db.pragma("journal_mode = WAL");
  db.exec(SCHEMA);
  return db;
}

export function upsertDesign(db: Database.Database, meta: Meta, analysis: string): void {
  const tx = db.transaction(() => {
    const existing = db.prepare("SELECT id FROM designs WHERE slug = ?").get(meta.slug) as { id: number } | undefined;
    if (existing) {
      for (const t of ["tags", "components", "colors"]) {
        db.prepare(`DELETE FROM ${t} WHERE design_id = ?`).run(existing.id);
      }
      db.prepare("DELETE FROM designs WHERE id = ?").run(existing.id);
      db.prepare("DELETE FROM designs_fts WHERE slug = ?").run(meta.slug);
    }
    const info = db.prepare(
      `INSERT INTO designs (slug, url, domain, title, source_type, platform, category, status, captured_at, note)
       VALUES (@slug, @url, @domain, @title, @source_type, @platform, @category, @status, @captured_at, @note)`
    ).run({
      slug: meta.slug, url: meta.url, domain: meta.domain, title: meta.title,
      source_type: meta.source_type, platform: meta.platform, category: meta.category,

    const insComp = db.prepare("INSERT INTO components (design_id, type, path, description) VALUES (?, ?, ?, ?)");

    ].join("\n");
    db.prepare(
      `INSERT INTO designs_fts (slug, title, category, tags, note, analysis, components_text)
       VALUES (?, ?, ?, ?, ?, ?, ?)`
    ).run(meta.slug, meta.title, meta.category, meta.tags.join(" "), meta.note, analysis, componentsText);
  });
  tx();
}

export function reindexAll(db: Database.Database): number {
  db.exec("DELETE FROM tags; DELETE FROM components; DELETE FROM colors; DELETE FROM designs; DELETE FROM designs_fts;");
  const slugs = listSlugs();
  for (const slug of slugs) upsertDesign(db, readMeta(slug), readAnalysis(slug));
  return slugs.length;
}

export type SearchArgs = {
  query?: string;
  tags?: string[];
  category?: string;
  source_type?: "web" | "app";
  limit?: number;
};

export type SearchHit = {
  slug: string; title: string; domain: string; category: string; source_type: string;
  status: string; captured_at: string; note: string; tags: string[]; snippet: string;
};

/** Turn free text into a safe FTS5 MATCH expression: quoted tokens, implicit AND. */
function ftsQuery(q: string): string | null {
  const tokens = q.toLowerCase().split(/[^a-z0-9]+/).filter(Boolean);
  return tokens.length ? tokens.map((t) => `"${t}"`).join(" ") : null;
}

export function searchDesigns(db: Database.Database, args: SearchArgs): SearchHit[] {
  const limit = args.limit ?? 5;
  let ordered: { slug: string; snippet: string }[];
  const match = args.query ? ftsQuery(args.query) : null;
  if (match) {
    ordered = db.prepare(
      `SELECT slug, snippet(designs_fts, -1, '[', ']', '…', 12) AS snippet
       FROM designs_fts WHERE designs_fts MATCH ? ORDER BY rank`
    ).all(match) as { slug: string; snippet: string }[];
  } else {
    ordered = (db.prepare("SELECT slug FROM designs ORDER BY captured_at DESC").all() as { slug: string }[])
      .map((r) => ({ slug: r.slug, snippet: "" }));
  }
  const hits: SearchHit[] = [];
  const rowStmt = db.prepare("SELECT * FROM designs WHERE slug = ?");
  const tagStmt = db.prepare("SELECT tag FROM tags WHERE design_id = ?");
  for (const { slug, snippet } of ordered) {
    const row = rowStmt.get(slug) as Record<string, unknown> | undefined;
    if (!row) continue;
    const tags = (tagStmt.all(row.id) as { tag: string }[]).map((t) => t.tag);
    if (args.category && row.category !== args.category) continue;
    if (args.source_type && row.source_type !== args.source_type) continue;
    if (args.tags && !args.tags.every((t) => tags.includes(t))) continue;
    hits.push({
      slug: row.slug as string, title: row.title as string, domain: row.domain as string,
      category: row.category as string, source_type: row.source_type as string,
      status: row.status as string, captured_at: row.captured_at as string,
      note: row.note as string, tags, snippet,
    });
    if (hits.length >= limit) break;
  }
  return hits;
}

export function listTagCounts(db: Database.Database): { tag: string; count: number }[] {
  return db.prepare("SELECT tag, COUNT(*) AS count FROM tags GROUP BY tag ORDER BY count DESC, tag").all() as {
    tag: string; count: number;
  }[];
}
```

```typescript
import fs from "node:fs";
import path from "node:path";
import sharp from "sharp";
import { designDir } from "./paths.js";
import type { Meta } from "./meta.js";

/** Canonical thumbnail per spec §4: web → desktop-fold.png, app → first screen. */
export function thumbnailSource(meta: Meta): string | null {
  const dir = designDir(meta.slug);
  const rel = meta.source_type === "web" ? "desktop-fold.png" : meta.screens[0]?.path;
  if (!rel) return null;
  const abs = path.join(dir, rel);
  return fs.existsSync(abs) ? abs : null;
}

export async function jpegBase64(
  imagePath: string,
  opts: { maxWidth?: number; maxHeight?: number } = {}
): Promise<{ data: string; mimeType: "image/jpeg" }> {
  const width = opts.maxWidth ?? (opts.maxHeight ? undefined : 768);
  const buf = await sharp(imagePath)
    .resize({ width, height: opts.maxHeight, fit: "inside", withoutEnlargement: true })
    .jpeg({ quality: 80 })
    .toBuffer();
  return { data: buf.toString("base64"), mimeType: "image/jpeg" };
}

export async function imageBlock(
  imagePath: string,
  opts: { maxWidth?: number; maxHeight?: number } = {}
): Promise<{ type: "image"; data: string; mimeType: "image/jpeg" }> {
  return { type: "image", ...(await jpegBase64(imagePath, opts)) };
}
```

```typescript
import fs from "node:fs";
import path from "node:path";
import { chromium, type Page } from "playwright";
import { Vibrant } from "node-vibrant/node";
import { designDir, ensureDir, makeSlug } from "../lib/paths.js";
import { MetaSchema, domainFromUrl, writeMeta, type Meta } from "../lib/meta.js";

const DESKTOP = { width: 1440, height: 900 };
const MOBILE = { width: 390, height: 844 };

// One combined selector: querySelectorAll dedupes elements matching multiple parts.
const SECTION_SELECTOR = [
  "header", "nav", "footer", "main > section", "body > section",
  "[class*=hero]", "[class*=pricing]", "[class*=testimonial]", "[class*=faq]",
].join(", ");

const COOKIE_SELECTORS = [
  "#onetrust-accept-btn-handler",
  "[id*=cookie i] button",
  "[class*=cookie i] button",
  "[class*=consent i] button",
];

async function dismissCookieBanners(page: Page): Promise<void> {
  for (const sel of COOKIE_SELECTORS) {
    try {
      const el = page.locator(sel).first();
      if (await el.isVisible({ timeout: 300 })) await el.click({ timeout: 1000 });
    } catch { /* best effort per spec §4 */ }
  }
}

async function autoScroll(page: Page): Promise<void> {
  await page.evaluate(async () => {
    await new Promise<void>((resolve) => {
      let total = 0;
      const step = () => {
        window.scrollBy(0, 600);
        total += 600;
        if (total >= document.body.scrollHeight || total > 30000) {
          window.scrollTo(0, 0);
          resolve();
        } else setTimeout(step, 120);
      };
      step();
    });
  });
  await page.waitForTimeout(400); // let lazy images settle
}

async function captureSections(page: Page, dir: string): Promise<Meta["components"]> {
  ensureDir(path.join(dir, "components"));
  const handles = await page.$$(SECTION_SELECTOR);
  const components: Meta["components"] = [];
  let i = 0;
  for (const h of handles) {
    if (components.length >= 15) break;
    try {
      const box = await h.boundingBox();
      if (!box || box.height < 100 || box.width < 200) continue;
      const rel = path.join("components", `section-${i}.png`);
      await h.screenshot({ path: path.join(dir, rel) });
      components.push({ type: "other", path: rel, description: "" });
      i++;
    } catch { /* detached/hidden elements are skippable */ }
  }
  return components;
}

async function collectCss(page: Page): Promise<string> {
  return page.evaluate(() => {
    let out = "";
    for (const sheet of Array.from(document.styleSheets)) {
      try {
        for (const rule of Array.from(sheet.cssRules)) out += rule.cssText + "\n";
      } catch { /* cross-origin sheets are unreadable; skip silently per spec */ }
    }
    return out;
  });
}

async function extractDeclaredTokens(page: Page) {
  return page.evaluate(() => {
    const cssVars: Record<string, string> = {};
    for (const sheet of Array.from(document.styleSheets)) {
      try {
        for (const rule of Array.from(sheet.cssRules)) {
          if (rule instanceof CSSStyleRule && rule.selectorText === ":root") {
            for (const name of Array.from(rule.style)) {
              if (name.startsWith("--")) cssVars[name] = rule.style.getPropertyValue(name).trim();
            }
          }
        }
      } catch { /* cross-origin */ }
    }
    const fonts = new Set<string>();
    const sizes = new Set<string>();
    document.querySelectorAll("h1,h2,h3,p,a,button,body").forEach((el) => {
      const cs = getComputedStyle(el);
      fonts.add(cs.fontFamily.split(",")[0].trim().replace(/['"]/g, ""));
      sizes.add(cs.fontSize);
    });
    return {
      cssVars,
      fonts: [...fonts],
      fontSizes: [...sizes].sort((a, b) => parseFloat(a) - parseFloat(b)),
    };
  });
}

async function empiricalPalette(imagePath: string) {
  const palette = await Vibrant.from(imagePath).getPalette();
  return Object.entries(palette)
    .filter(([, swatch]) => swatch)
    .map(([name, swatch]) => ({ name, hex: swatch!.hex, population: swatch!.population }));
}

export async function captureWeb(url: string, opts: { note?: string; force?: boolean } = {}): Promise<string> {
  const domain = domainFromUrl(url);
  const slug = makeSlug(domain);
  const dir = designDir(slug);
  if (fs.existsSync(dir)) {
    if (!opts.force) throw new Error(`Entry "${slug}" already exists for today; pass force to re-capture`);
    fs.rmSync(dir, { recursive: true, force: true });
  }

  const browser = await chromium.launch();
  let status: Meta["status"] = "needs-analysis";
  const degrade = () => { status = "partial"; };
  try {
    const ctx = await browser.newContext({ viewport: DESKTOP });
    const page = await ctx.newPage();
    const resp = await page.goto(url, { waitUntil: "domcontentloaded", timeout: 30000 });
    if (!resp || resp.status() >= 400) {
      throw new Error(`Failed to load ${url}: HTTP ${resp ? resp.status() : "no response"}`);
    }
    ensureDir(dir); // only after a successful load — hard failures create no entry
    await page.waitForLoadState("networkidle", { timeout: 15000 }).catch(degrade);
    await dismissCookieBanners(page);
    await autoScroll(page);

    await page.screenshot({ path: path.join(dir, "desktop-fold.png") }); // viewport = above the fold
    await page.screenshot({ path: path.join(dir, "desktop.png"), fullPage: true });
    const components = await captureSections(page, dir);

    const title = await page.title();
    fs.writeFileSync(path.join(dir, "page.html"), await page.content());
    fs.writeFileSync(path.join(dir, "styles.css"), await collectCss(page));
    const declared = await extractDeclaredTokens(page);
    await ctx.close();

    // Mobile pass — degradation, not failure, if it breaks.
    try {
      const mctx = await browser.newContext({ viewport: MOBILE });
      const mpage = await mctx.newPage();
      await mpage.goto(url, { waitUntil: "domcontentloaded", timeout: 30000 });
      await autoScroll(mpage);
      await mpage.screenshot({ path: path.join(dir, "mobile.png"), fullPage: true });
      await mctx.close();
    } catch { degrade(); }

    const palette = await empiricalPalette(path.join(dir, "desktop-fold.png"));
    fs.writeFileSync(
      path.join(dir, "tokens.json"),
      JSON.stringify({ declared, empiricalPalette: palette }, null, 2)
    );

    const meta = MetaSchema.parse({
      slug, source_type: "web", platform: "web", url, domain, title,
      category: "other", status, captured_at: new Date().toISOString(),
      note: opts.note ?? "", tags: [], palette: [], typography: {}, components, screens: [],
    });
    writeMeta(meta);
    return slug;
  } finally {
    await browser.close();
  }
}
```

```typescript
import { execFile } from "node:child_process";
import { promisify } from "node:util";
import fs from "node:fs";
import path from "node:path";
import { designDir } from "../lib/paths.js";
import {
  LibrarianOutputSchema, readAnalysis, readMeta, writeAnalysis, writeMeta,
  type LibrarianOutput, type Meta,
} from "../lib/meta.js";
import { STYLE_TAGS } from "../lib/vocab.js";
import { openDb, upsertDesign } from "../lib/db.js";
import { buildPrompt } from "./prompt.js";

const execFileAsync = promisify(execFile);

async function runClaude(prompt: string, dir: string): Promise<string> {
  const bin = process.env.GOOD_EYE_CLAUDE_BIN ?? "claude";
  const model = process.env.GOOD_EYE_MODEL ?? "sonnet";
  const { stdout } = await execFileAsync(
    bin,
    ["-p", prompt, "--output-format", "json", "--model", model, "--allowedTools", "Read", "--add-dir", dir],
    { maxBuffer: 32 * 1024 * 1024, timeout: 300_000 }
  );
  const envelope = JSON.parse(stdout) as { result?: string };
  if (typeof envelope.result !== "string") throw new Error("claude -p envelope had no result string");
  return envelope.result;
}

/** Pull a JSON object out of possibly fence-wrapped text. */
function extractJson(text: string): unknown {
  const start = text.indexOf("{");
  const end = text.lastIndexOf("}");
  if (start === -1 || end <= start) throw new Error("no JSON object in librarian output");
  return JSON.parse(text.slice(start, end + 1));
}

/** Keep vocabulary tags plus at most 3 free-form extras (spec §5). */
function trimTags(tags: string[]): string[] {
  const known = tags.filter((t) => (STYLE_TAGS as readonly string[]).includes(t));
  const extras = tags.filter((t) => !(STYLE_TAGS as readonly string[]).includes(t)).slice(0, 3);
  return [...new Set([...known, ...extras])];
}

function applyLibrarian(meta: Meta, out: LibrarianOutput, dir: string): Meta {
  meta.category = out.category;
  meta.tags = trimTags(out.tags);
  meta.palette = out.palette;
  meta.typography = out.typography;

  if (meta.source_type === "web") {
    const used = new Set<string>();
    for (const item of out.components) {
      const existing = meta.components.find((c) => c.path === item.file);
      if (!existing) continue; // librarian referenced a file we never captured
      let base = item.type;
      let n = 2;
      while (used.has(base)) base = `${item.type}-${n++}`;
      used.add(base);
      const newRel = path.join("components", `${base}.png`);
      fs.renameSync(path.join(dir, existing.path), path.join(dir, newRel));
      existing.path = newRel;
      existing.type = item.type;
      existing.description = item.description;
    }
  } else {
    for (const item of out.screens) {
      const existing = meta.screens.find((s) => s.path === item.file);
      if (!existing) continue;
      existing.name = item.name;
      existing.description = item.description;
    }
  }

  writeAnalysis(meta.slug, out.review);
  if (meta.status === "needs-analysis") meta.status = "complete"; // partial stays partial
  return meta;
}

export async function analyze(slug: string): Promise<Meta> {
  const dir = designDir(slug);
  let meta = readMeta(slug);
  const basePrompt = buildPrompt(meta, dir);
  let lastError = "";

  for (let attempt = 0; attempt < 2; attempt++) {
    const prompt = attempt === 0
      ? basePrompt
      : `${basePrompt}\n\nYour previous output failed validation:\n${lastError}\nOutput ONLY the corrected JSON object.`;
    try {
      const raw = await runClaude(prompt, dir);
      const validated = LibrarianOutputSchema.safeParse(extractJson(raw));
      if (!validated.success) {
        lastError = validated.error.message;
        continue;
      }
      meta = applyLibrarian(meta, validated.data, dir);
      break;
    } catch (err) {
      lastError = err instanceof Error ? err.message : String(err);
    }
  }
  if (meta.status === "needs-analysis") {
    console.error(`good-eye: analysis failed for ${slug}, left as needs-analysis (${lastError})`);
  }

  writeMeta(meta);
  const db = openDb();
  upsertDesign(db, meta, readAnalysis(slug));
  db.close();
  return meta;
}
```

```typescript
import fs from "node:fs";
import os from "node:os";
import path from "node:path";
import { Vibrant } from "node-vibrant/node";
import { designDir, ensureDir, makeSlug } from "../lib/paths.js";
import { MetaSchema, writeMeta } from "../lib/meta.js";

const IMAGE_EXT = /\.(png|jpe?g|webp)$/i;

export async function ingestFolder(args: {
  folder: string;
  name: string;
  platform: "ios" | "android" | "macos" | "web";
  note?: string;
}): Promise<string> {
  const files = fs.readdirSync(args.folder).filter((f) => IMAGE_EXT.test(f)).sort();
  if (files.length === 0) throw new Error(`No images (.png/.jpg/.webp) found in ${args.folder}`);

  const slug = makeSlug(args.name);
  const dir = designDir(slug);
  if (fs.existsSync(dir)) throw new Error(`Entry "${slug}" already exists for today`);
  ensureDir(path.join(dir, "screens"));

  const screens = files.map((f, i) => {
    const ext = path.extname(f).toLowerCase().replace("jpeg", "jpg");
    const rel = path.join("screens", `screen-${String(i + 1).padStart(2, "0")}${ext}`);
    fs.copyFileSync(path.join(args.folder, f), path.join(dir, rel));
    return { name: `screen-${i + 1}`, path: rel, description: "" };
  });

  const palette = await Vibrant.from(path.join(dir, screens[0].path)).getPalette();
  const empiricalPalette = Object.entries(palette)
    .filter(([, s]) => s)
    .map(([name, s]) => ({ name, hex: s!.hex, population: s!.population }));
  fs.writeFileSync(path.join(dir, "tokens.json"), JSON.stringify({ declared: {}, empiricalPalette }, null, 2));

  const meta = MetaSchema.parse({
    slug, source_type: "app", platform: args.platform, url: null, domain: args.name,
    title: args.name, category: "other", status: "needs-analysis",
    captured_at: new Date().toISOString(), note: args.note ?? "",
    tags: [], palette: [], typography: {}, components: [], screens,
  });
  writeMeta(meta);
  return slug;
}

export function isStoreUrl(url: string): boolean {
  return /(^|\.)apps\.apple\.com|(^|\.)play\.google\.com/.test(new URL(url).hostname);
}

/** Best-effort per spec §4 — store listing markup changes; folder ingestion is the reliable path. */
export function extractListingImages(html: string): string[] {
  const urls = new Set<string>();
  for (const m of html.matchAll(/https:\/\/[a-z0-9-]+\.mzstatic\.com\/[^"'\s,]+\.(?:png|jpe?g|webp)[^"'\s,]*/gi)) {
    urls.add(m[0]);
  }
  for (const m of html.matchAll(/https:\/\/play-lh\.googleusercontent\.com\/[^"'\s,)]+/gi)) {
    urls.add(m[0]);
  }
  return [...urls].filter((u) => !/icon/i.test(u)).slice(0, 12);
}

export async function ingestAppStore(url: string, note?: string): Promise<string> {
  const res = await fetch(url, { headers: { "user-agent": "Mozilla/5.0 (Macintosh) good-eye/0.1" } });
  if (!res.ok) throw new Error(`Store listing fetch failed: HTTP ${res.status}`);
  const html = await res.text();
  const images = extractListingImages(html);
  if (images.length < 2) {
    throw new Error(
      "Could not scrape enough screenshots from the listing. Save screenshots to a folder and ingest with { folder, name, platform } instead."
    );
  }
  const titleMatch = html.match(/<title>([^<]+)<\/title>/i);
  const name = (titleMatch?.[1] ?? new URL(url).pathname).split(/[–|-]/)[0].trim().slice(0, 40) || "app";
  const platform = new URL(url).hostname.includes("apple") ? "ios" as const : "android" as const;

  const tmp = fs.mkdtempSync(path.join(os.tmpdir(), "good-eye-store-"));
  let i = 0;
  for (const imgUrl of images) {
    const r = await fetch(imgUrl, { headers: { "user-agent": "Mozilla/5.0 (Macintosh) good-eye/0.1" } });
    if (!r.ok) continue;
    const ext = imgUrl.match(/\.(png|jpe?g|webp)/i)?.[1] ?? "png";
    fs.writeFileSync(path.join(tmp, `shot-${String(i++).padStart(2, "0")}.${ext.replace("jpeg", "jpg")}`),
      Buffer.from(await r.arrayBuffer()));
  }
  const slug = await ingestFolder({ folder: tmp, name, platform, note });
  // Record the listing URL on the entry (folder ingestion sets url: null).
  const metaPath = path.join(designDir(slug), "meta.json");
  const meta = JSON.parse(fs.readFileSync(metaPath, "utf8"));
  meta.url = url;
  fs.writeFileSync(metaPath, JSON.stringify(meta, null, 2));
  return slug;
}
```

```typescript
import { captureWeb } from "./capture/web.js";
import { ingestAppStore, ingestFolder, isStoreUrl } from "./capture/app.js";
import { analyze } from "./librarian/analyze.js";
import { openDb, reindexAll, searchDesigns, listTagCounts } from "./lib/db.js";

type Parsed = { positional: string[]; flags: Record<string, string | boolean>; tags: string[] };

function parseArgs(argv: string[]): Parsed {
  const out: Parsed = { positional: [], flags: {}, tags: [] };
  for (let i = 0; i < argv.length; i++) {
    const a = argv[i];
    if (a === "--force") out.flags.force = true;
    else if (a === "--tag") out.tags.push(argv[++i]);
    else if (a.startsWith("--")) out.flags[a.slice(2)] = argv[++i];
    else out.positional.push(a);
  }
  return out;
}

async function addOne(target: string, note: string | undefined, force: boolean): Promise<void> {
  const slug = isStoreUrl(target)
    ? await ingestAppStore(target, note)
    : await captureWeb(target, { note, force });
  const meta = await analyze(slug);
  console.log(`saved: ${slug} [${meta.status}] tags=${meta.tags.join(",")}`);
}

async function main(): Promise<void> {
  const [cmd, ...rest] = process.argv.slice(2);
  const { positional, flags, tags } = parseArgs(rest);
  const note = typeof flags.note === "string" ? flags.note : undefined;

  switch (cmd) {
    case "add": {
      if (flags.folder) {
        const slug = await ingestFolder({
          folder: String(flags.folder),
          name: String(flags.name ?? "app"),
          platform: (flags.platform as "ios" | "android" | "macos" | "web") ?? "ios",
          note,
        });
        const meta = await analyze(slug);
        console.log(`saved: ${slug} [${meta.status}] tags=${meta.tags.join(",")}`);
        break;
      }
      if (positional.length === 0) throw new Error("usage: add <url...> | add --folder <p> --name <n> --platform <p>");
      for (const url of positional) await addOne(url, note, Boolean(flags.force));
      break;
    }
    case "capture": {
      if (!positional[0]) throw new Error("usage: capture <url>");
      console.log(await captureWeb(positional[0], { note, force: Boolean(flags.force) }));
      break;
    }
    case "analyze": {
      if (!positional[0]) throw new Error("usage: analyze <slug>");
      const meta = await analyze(positional[0]);
      console.log(`analyzed: ${meta.slug} [${meta.status}]`);
      break;
    }
    case "search": {
      const db = openDb();
      const hits = searchDesigns(db, {
        query: positional.join(" ") || undefined,
        tags: tags.length ? tags : undefined,
        category: typeof flags.category === "string" ? flags.category : undefined,
        limit: flags.limit ? Number(flags.limit) : undefined,
      });
      for (const h of hits) {
        console.log(`${h.slug}  [${h.category}] [${h.source_type}] tags=${h.tags.join(",")}  ${h.snippet}`);
      }
      if (hits.length === 0) console.log("no matches");
      db.close();
      break;
    }
    case "tags": {
      const db = openDb();
      for (const t of listTagCounts(db)) console.log(`${t.tag}\t${t.count}`);
      db.close();
      break;
    }
    case "reindex": {
      const db = openDb();
      console.log(`reindexed ${reindexAll(db)} entries`);
      db.close();
      break;
    }
    default:
      throw new Error(`unknown command "${cmd ?? ""}" — expected add|capture|analyze|search|tags|reindex`);
  }
}

main().catch((err) => {
  console.error(err instanceof Error ? err.message : String(err));
  process.exit(1);
});
```

```typescript
import path from "node:path";
import { z } from "zod";
import { McpServer } from "@modelcontextprotocol/sdk/server/mcp.js";
import { StdioServerTransport } from "@modelcontextprotocol/sdk/server/stdio.js";
import { designDir } from "./lib/paths.js";
import { readAnalysis, readMeta, type Meta } from "./lib/meta.js";
import { openDb, reindexAll, searchDesigns, listTagCounts, type SearchHit } from "./lib/db.js";
import { imageBlock, thumbnailSource } from "./lib/images.js";
import { STYLE_TAGS, CATEGORIES, COMPONENT_TYPES } from "./lib/vocab.js";
import { captureWeb } from "./capture/web.js";
import { ingestAppStore, ingestFolder, isStoreUrl } from "./capture/app.js";
import { analyze } from "./librarian/analyze.js";

type Block =
  | { type: "text"; text: string }
  | { type: "image"; data: string; mimeType: "image/jpeg" };
type ToolResult = { content: Block[]; isError?: boolean };

const server = new McpServer({ name: "good-eye", version: "0.1.0" });

function ok(content: Block[]): ToolResult {
  return { content: content.length ? content : [{ type: "text", text: "No matches." }] };
}
function fail(err: unknown): ToolResult {
  const msg = err instanceof Error ? err.message : String(err);
  return { content: [{ type: "text", text: `Error: ${msg}` }], isError: true };
}

function hitText(h: SearchHit): string {
  return [
    `## ${h.slug}`,
    `${h.title} — ${h.domain} | ${h.category} | ${h.source_type} | ${h.status}`,
    h.tags.length ? `tags: ${h.tags.join(", ")}` : "",
    h.note ? `note: ${h.note}` : "",
    h.snippet ? `match: ${h.snippet}` : "",
  ].filter(Boolean).join("\n");
}

function metaText(meta: Meta, analysis: string): string {
  const palette = meta.palette.map((p) => `${p.hex} (${p.role})`).join(", ");
  const items = meta.source_type === "web"
    ? meta.components.map((c) => `- ${c.type}: ${c.description} (${c.path})`)
    : meta.screens.map((s) => `- ${s.name}: ${s.description} (${s.path})`);
  return [
    `# ${meta.slug}`,
    `${meta.title} — ${meta.url ?? meta.domain}`,
    `category: ${meta.category} | platform: ${meta.platform} | status: ${meta.status} | captured: ${meta.captured_at}`,
    `tags: ${meta.tags.join(", ")}`,
    `palette: ${palette}`,
    `typography: ${meta.typography.families.join(", ")} — ${meta.typography.scale} ${meta.typography.notes}`,
    meta.note ? `curator note: ${meta.note}` : "",
    "", items.join("\n"), "", "## Review", analysis || "(not yet analyzed)",
  ].filter((l) => l !== "").join("\n");
}

server.registerTool("search_designs", {
  description:
    "Search the personal design inspiration library (websites + apps). Returns ranked matches with metadata and thumbnail images. Use before proposing any visual design.",
  inputSchema: {
    query: z.string().optional().describe("Free text: matched against titles, tags, analyses, component descriptions"),
    tags: z.array(z.string()).optional().describe("Style tags, AND semantics — see list_tags"),
    category: z.string().optional(),
    source_type: z.enum(["web", "app"]).optional(),
    limit: z.number().int().min(1).max(20).default(5),
  },
}, async (args) => {
  try {
    const db = openDb();
    const hits = searchDesigns(db, args);
    db.close();
    const content: Block[] = [];
    for (const h of hits) {
      content.push({ type: "text", text: hitText(h) });
      const src = thumbnailSource(readMeta(h.slug));
      if (src) content.push(await imageBlock(src, { maxWidth: 768 }));
    }
    return ok(content);
  } catch (err) { return fail(err); }
});

server.registerTool("get_design", {
  description: "Full detail for one library entry: metadata, palette, typography, written design review, and images.",
  inputSchema: {
    slug: z.string(),
    images: z.enum(["fold", "full", "components", "none"]).default("fold"),
  },
}, async ({ slug, images }) => {
  try {
    const meta = readMeta(slug);
    const dir = designDir(slug);
    const content: Block[] = [{ type: "text", text: metaText(meta, readAnalysis(slug)) }];
    if (images === "fold") {
      const src = thumbnailSource(meta);
      if (src) content.push(await imageBlock(src, { maxWidth: 1000 }));
    } else if (images === "full") {
      if (meta.source_type === "web") {
        for (const f of ["desktop.png", "mobile.png"]) {
          content.push(await imageBlock(path.join(dir, f), { maxHeight: 1600 }));
        }
      } else {
        for (const s of meta.screens.slice(0, 8)) {
          content.push(await imageBlock(path.join(dir, s.path), { maxHeight: 1600 }));
        }
      }
    } else if (images === "components") {
      const items = meta.source_type === "web" ? meta.components : meta.screens;
      for (const c of items.slice(0, 10)) {
        content.push(await imageBlock(path.join(dir, c.path), { maxWidth: 1000 }));
      }
    }
    return ok(content);
  } catch (err) { return fail(err); }
});

server.registerTool("list_components", {
  description: `Show component crops of one type across all designs (e.g. every "pricing" section). Types: ${COMPONENT_TYPES.join(", ")}; app screens are "screen:<name>".`,
  inputSchema: {
    type: z.string().describe("Component type to collect"),
    query: z.string().optional().describe("Substring filter on the component description"),
    limit: z.number().int().min(1).max(15).default(8),
  },
}, async ({ type, query, limit }) => {
  try {
    const db = openDb();
    const rows = db.prepare(
      `SELECT d.slug, c.type, c.path, c.description FROM components c
       JOIN designs d ON d.id = c.design_id
       WHERE c.type = ? AND (? IS NULL OR c.description LIKE '%' || ? || '%')
       ORDER BY d.captured_at DESC LIMIT ?`
    ).all(type, query ?? null, query ?? null, limit) as { slug: string; type: string; path: string; description: string }[];
    db.close();
    const content: Block[] = [];
    for (const r of rows) {
      content.push({ type: "text", text: `${r.slug} — ${r.type}: ${r.description}` });
      content.push(await imageBlock(path.join(designDir(r.slug), r.path), { maxWidth: 1000 }));
    }
    return ok(content);
  } catch (err) { return fail(err); }
});

server.registerTool("compare_designs", {
  description: "Side-by-side comparison of 2-4 entries: thumbnails plus palette/typography/tag differences.",
  inputSchema: { slugs: z.array(z.string()).min(2).max(4) },
}, async ({ slugs }) => {
  try {
    const content: Block[] = [];
    for (const slug of slugs) {
      const meta = readMeta(slug);
      content.push({
        type: "text",
        text: [
          `## ${slug}`,

        ].join("\n"),
      });
      const src = thumbnailSource(meta);
      if (src) content.push(await imageBlock(src, { maxWidth: 768 }));
    }
    return ok(content);
  } catch (err) { return fail(err); }
});

server.registerTool("list_tags", {
  description: "The controlled vocabularies (style tags, categories, component types) with usage counts — consult before searching.",
  inputSchema: {},
}, async () => {
  try {
    const db = openDb();
    const counts = new Map(listTagCounts(db).map((t) => [t.tag, t.count]));
    db.close();
    const tagLines = STYLE_TAGS.map((t) => `${t} (${counts.get(t) ?? 0})`).join(", ");
    const extras = [...counts.keys()].filter((t) => !(STYLE_TAGS as readonly string[]).includes(t));
    return ok([{
      type: "text",
      text: [
        `Style tags: ${tagLines}`,
        extras.length ? `Free-form tags in use: ${extras.map((t) => `${t} (${counts.get(t)})`).join(", ")}` : "",
        `Categories: ${CATEGORIES.join(", ")}`,
        `Component types: ${COMPONENT_TYPES.join(", ")}`,
      ].filter(Boolean).join("\n\n"),
    }]);
  } catch (err) { return fail(err); }
});

server.registerTool("add_design", {
  description:
    "Add designs to the library. Web/App-Store/Play-Store URLs are captured + analyzed (~1-3 min each). Alternatively ingest a folder of your own app screenshots (folder requires name + platform). Provide exactly one of urls|folder.",
  inputSchema: {
    urls: z.array(z.string().url()).optional(),
    folder: z.string().optional().describe("Absolute path to a folder of screenshots"),
    name: z.string().optional().describe("App name (required with folder)"),
    platform: z.enum(["ios", "android", "macos", "web"]).optional(),
    note: z.string().optional().describe("Why this design is worth saving — gets indexed"),
    force: z.boolean().default(false).describe("Re-capture over a same-day entry"),
  },
}, async ({ urls, folder, name, platform, note, force }) => {
  try {
    if ((urls ? 1 : 0) + (folder ? 1 : 0) !== 1) {
      throw new Error("Provide exactly one of: urls, folder");
    }
    const lines: string[] = [];
    if (folder) {
      if (!name || !platform) throw new Error("folder ingestion requires name and platform");
      const slug = await ingestFolder({ folder, name, platform, note });
      const meta = await analyze(slug);
      lines.push(`saved: ${slug} [${meta.status}] tags=${meta.tags.join(",")}`);
    } else {
      for (const url of urls!) {
        console.error(`good-eye: capturing ${url}…`);
        try {
          const slug = isStoreUrl(url) ? await ingestAppStore(url, note) : await captureWeb(url, { note, force });
          console.error(`good-eye: analyzing ${slug}…`);
          const meta = await analyze(slug);
          lines.push(`saved: ${slug} [${meta.status}] tags=${meta.tags.join(",")}`);
        } catch (err) {
          lines.push(`failed: ${url} — ${err instanceof Error ? err.message : err}`);
        }
      }
    }
    return ok([{ type: "text", text: lines.join("\n") }]);
  } catch (err) { return fail(err); }
});

server.registerTool("reindex", {
  description: "Rebuild the search catalog from the files on disk (meta.json is the source of truth).",
  inputSchema: {},
}, async () => {
  try {
    const db = openDb();
    const n = reindexAll(db);
    db.close();
    return ok([{ type: "text", text: `Reindexed ${n} entries.` }]);
  } catch (err) { return fail(err); }
});

await server.connect(new StdioServerTransport());
console.error("good-eye MCP server ready");
```

```markdown
# Good Eye — personal design reference library

A curated library of designs Gleb rates highly, stored locally with full-page screenshots,
component crops, extracted palettes/typography, and a written review per entry.
Access it through the `good-eye` MCP tools. This skill is the METHOD; the tools are the hands.

## When to consult (mandatory before proposing visuals)

Any task that produces UI: new designs, redesigns, "make it look better", component work,
style/theme decisions, design critique. Search FIRST, design SECOND.

## Query strategy

1. Run 2–4 searches, broad → narrow:
   - category first: `search_designs {category: "saas-landing"}`
   - then style: `search_designs {tags: ["dark-mode", "typography-led"]}`
   - then the specific component: `list_components {type: "pricing"}`
2. Unsure of vocabulary? `list_tags` shows every tag/category with usage counts.
3. Look at the returned images — the thumbnails are real pixels, not descriptions.

## Reference discipline

- Pull 2–4 references max; `get_design` (images: "fold" or "components") on the finalists.
- Extract CONCRETE tokens: hex values, type scale, spacing rhythm, one signature move each.
- SYNTHESIZE, never copy: combine moves across references; adapt palettes to the brand at hand.
- Name influences in your output ("pricing density from <slug>, palette discipline from <slug>").
- `compare_designs` when torn between directions.

## Curation etiquette

- User shares a great link mid-conversation → offer `add_design` with a note capturing WHY
  ("their pricing table", "hero motion"). The note gets indexed — future searches hit it.
- Apps: App Store / Play Store URLs work via add_design urls; personal screenshots via
  `add_design {folder, name, platform}`.
- add_design takes ~1–3 min per site (capture + analysis). Say so before running it.

## Fallback without MCP

The library lives at `~/claude-has-a-good-eye`. CLI equivalent:
`node --import tsx ~/claude-has-a-good-eye/src/cli.ts search <query> [--tag t] [--category c]`
(also: `add <url>`, `tags`, `reindex`). Images are at
`~/claude-has-a-good-eye/data/designs/<slug>/` — Read them directly.
```

- [ ] **Step 3: Write scripts/install.sh and make it executable**

```bash
#!/bin/bash
set -euo pipefail
REPO="$(cd "$(dirname "$0")/.." && pwd)"
DRY=0
[ "${1:-}" = "--dry-run" ] && DRY=1

run() { if [ "$DRY" = 1 ]; then echo "DRY: $*"; else "$@"; fi }

NODE_BIN="$(command -v node)"
TSX="$REPO/node_modules/tsx/dist/cli.mjs"
SERVER="$REPO/src/server.ts"
HOOK="$REPO/hooks/design-prompt.sh"
SETTINGS="$HOME/.claude/settings.json"

echo "== good-eye install (repo: $REPO) =="

# 1. Dependencies
run npm --prefix "$REPO" install
if [ "$DRY" = 1 ]; then echo "DRY: npx playwright install chromium"; else (cd "$REPO" && npx playwright install chromium); fi
if [ "$DRY" = 0 ] && [ ! -f "$TSX" ]; then echo "ERROR: $TSX not found after npm install" >&2; exit 1; fi

# 2. Skill symlink
run mkdir -p "$HOME/.claude/skills"
run ln -sfn "$REPO/skill" "$HOME/.claude/skills/good-eye"

# 3. MCP server (user scope, absolute paths — GUI apps have a minimal PATH)
if [ "$DRY" = 1 ]; then
  echo "DRY: claude mcp add --scope user good-eye -- $NODE_BIN $TSX $SERVER"
else
  claude mcp remove --scope user good-eye >/dev/null 2>&1 || true
  claude mcp add --scope user good-eye -- "$NODE_BIN" "$TSX" "$SERVER"
fi

# 4. UserPromptSubmit hook (backup, then dedupe-merge)
if [ "$DRY" = 1 ]; then
  echo "DRY: merge hook into $SETTINGS (command: $HOOK)"
else
  [ -f "$SETTINGS" ] && cp "$SETTINGS" "$SETTINGS.backup-$(date +%s)"
  HOOK_CMD="$HOOK" SETTINGS_FILE="$SETTINGS" "$NODE_BIN" -e '
    const fs = require("fs");
    const file = process.env.SETTINGS_FILE, cmd = process.env.HOOK_CMD;
    const s = fs.existsSync(file) ? JSON.parse(fs.readFileSync(file, "utf8")) : {};
    s.hooks ??= {};
    s.hooks.UserPromptSubmit ??= [];
    const present = JSON.stringify(s.hooks.UserPromptSubmit).includes(cmd);
    if (!present) s.hooks.UserPromptSubmit.push({ hooks: [{ type: "command", command: cmd }] });
    fs.writeFileSync(file, JSON.stringify(s, null, 2));
    console.error(present ? "hook already installed" : "hook installed");
  '
fi

# 5. Manual snippets for other clients
cat <<EOF

== Claude Desktop: add to claude_desktop_config.json ==
{
  "mcpServers": {
    "good-eye": { "command": "$NODE_BIN", "args": ["$TSX", "$SERVER"] }
  }
}

== Codex: add to ~/.codex/config.toml ==
[mcp_servers.good-eye]
command = "$NODE_BIN"
args = ["$TSX", "$SERVER"]

Done. Try: claude → "search my design library for pricing pages"
EOF
```

```markdown
typography, and a written review for every site/app worth stealing from — searchable by

    bash scripts/install.sh

- Add: tell Claude "add https://stripe.com to the design library — look at their pricing"
  (or `node --import tsx src/cli.ts add <url> --note "..."`)
- Apps: paste an App Store / Play Store link, or ingest a folder of screenshots
- Search happens automatically when you ask Claude to design something; manual:
  `node --import tsx src/cli.ts search dark pricing --tag dark-mode`

- `data/designs/<slug>/` — meta.json, analysis.md, screenshots, tokens (source of truth, gitignored)
- `data/catalog.db` — derived SQLite/FTS5 index (`cli.ts reindex` rebuilds it)
- `src/` — capture pipeline, librarian, CLI, MCP server; `skill/`, `hooks/`, `scripts/`

Spec: `docs/superpowers/specs/2026-07-11-design-inspiration-db-design.md`
```
